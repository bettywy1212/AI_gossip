# AI 八卦特刊 · 黑客松 Pitch 方案 & PPT 分镜

> 最新版：正式路演 = **PPT 讲故事** + **编辑部入口现场体验**。  
> 蒲公英：不作第五主题 / 不作开场解释；只在「发出去」那一拍作为仪式与视觉（吹一口 → 种子卡）。  
> 团队：解决痛点的小工坊——去伪存真，只留真需求，小小痛点也能被好好安放。

**建议总时长**：PPT 约 2.5–3 分钟（12 页）→ 入口现场约 1.5–2 分钟 → Q&A。

---

## 一、Pitch 总策略

### 一条因果链（整场只讲这个）

```text
我们自己读不进去
  → 拆成四类真卡点
  → 做成降解码成本的吃瓜特刊
  → 用接头暗号让人认出自己
  → 吹给同类（蒲公英 = 交给风）
  → 同伙读完才算落地生根
```

### 三类观众各吃哪几页


| 观众       | PPT 页  | 现场入口          |
| -------- | ------ | ------------- |
| 同类痛点     | P2–P4  | 对暗号、领身份       |
| 创作者      | P5–P7  | 痛点→机制→吹出去     |
| 投资人 / 评委 | P8–P10 | 供给可规模化 + 蓝海一句 |


### 和入口的分工（防复读）


| 内容                     | PPT      | 入口现场      |
| ---------------------- | -------- | --------- |
| 团队 / 原点 / 定位 / 竞品 / 后续 | ✅        | ❌ 少讲      |
| 人物·算盘·漫画·出处四条规矩        | 点到即可     | ✅ 完整盖章    |
| 四类角色名（工牌）              | 一笔带过     | ✅ 揭晓主场    |
| 「吹一口试试」+ 蒲公英动效         | 静帧示意 1 页 | ✅ 真机演示    |
| 「今晚的瓜已经切好，就差你一个」       | ❌        | ✅ 仅入口 CTA |




### 蒲公英怎么出现在 Pitch 里（不生硬）

- **不说**「我们不是做主题」「主办方要求融入」。  
- **只说动作**：认出自己之后，要把种子交给风。  
- PPT 里蒲公英最多 **1 页主戏 + 1 处角标**；其余页零蒲公英插画。  
- 口播最多一句隐喻，立刻接产品证据。

## 三、PPT 分镜（12 页）

每页格式：**画面结构 → 上屏文案 → 口播（逐字）→ 时长 → 备注**。  
Figma 可一页一 Frame；主色沿用特刊气质（纸感/墨色），蒲公英鹅黄 `#E4C55E` 仅 P7 印章/绒毛点缀。

### P1 · 封面｜开场钩子（10s）

**画面**  

- 大标题品牌区：`AI 八卦特刊` / `AI GOSSIP WEEKLY`  
- 副标题钩子（占视觉中心）  
- 角落极小：小工坊三字或日期；**无蒲公英大图**

**上屏文案**  

```
AI 八卦特刊
刷 AI 新闻时，你总在哪一步悄悄溜走？
```

**口播**  

> 大家好，我们是 AI 八卦特刊。我们不是又做了一个资讯站——我们先问一句：刷 AI 新闻时，你总在哪一步悄悄溜走？

**备注**：钩子与入口封面同问句，方便后面现场呼应；PPT 不展开全家福。

---



### P2 · 团队｜小工坊（12s）

**画面**  

- 左或上：团队定义 3 行  
- 下：三人角色条（时秒 / 韩婧 / Danielle）  
- 可用三个简单工位图标，勿用大头照拼盘

**上屏文案**  

```
解决痛点的小工坊
去伪存真，只留真需求
小小痛点，也能被好好安放

产品设计及传播 · 时秒
前端实现 · 韩婧
UI/UX · Danielle
```

**口播**  

> 我们是一个解决痛点的小工坊：去伪存真，只留下真需求；小小痛点，也能被好好安放。产品设计及传播是时秒，前端是韩婧，UI/UX 是 Danielle。工坊里的人，自己就是用户。

**金句**：先让自己爽，再让同类安心。（可作页脚小字）

---



### P3 · 原点｜Maker = User（12s）

**画面**  

- 左：一条严肃通稿被划走的示意（模糊截图即可）  
- 右：大字金句

**上屏文案**  

```
想跟上 AI，正经报道读不完
团队成员 = 用户本身

先让自己爽，再让同类安心
```

**口播**  

> 叙事原点很简单：我们想跟上 AI，但正经报道读不完。过载、通稿过敏、上课感、已读未回——我们天天踩。产品不是旁观痛点，是先把自己安放好。

---



### P4 · 用户｜四类真卡点（18s）

**画面**  

- 2×2 四格，用**类型名**（勿用工牌角色插画抢入口戏）  
- 每格一行生活句，短

**上屏文案**  

```
过载型　　脑子已经下班，读不动高密度长文
形式排斥型　一见通稿形式就想走，需要戏剧性进场
学习厌恶型　想懂，但拒绝上课感
执行型　　收藏很多，真正读完总差一步

不是不关心，是解码成本太高
```

**口播**  

> 阅读阻塞不是小众问题。四种卡点：过载、形式排斥、学习厌恶、执行难启动。不是不关心，是解码成本太高。

**备注**：角色名（电量见底记者等）留给入口揭晓。

---



### P5 · 定位｜产品是什么（15s）

**画面**  

- 中央一句定位  
- 下方四个词芯片（轻量，非入口盖章动画）：人物 · 算盘 · 漫画 · 出处  
- 可配一张正刊卡片缩略（漫画+一句话吃瓜）

**上屏文案**  

```
利用好奇心，无痛阅读新闻

正经通稿 → 连载剧式吃瓜
有人 · 有算盘 · 有漫画 · 有出处
```

**口播**  

> 所以定位很窄：利用好奇心，无痛阅读新闻。把严肃 AI 通稿改成能追的吃瓜连载——有人、有算盘、有漫画、有出处。要娱乐感，不要上课感。

**备注**：四条只点名；完整「编辑部立规矩」留给入口 P 盖章幕。

---



### P6 · 机制｜痛点如何变成产品（20s）

**画面**  

- 左列「卡点」→ 右列「机制」四条箭头  
- 底条：供给 `抓热点 → 改写成瓜 → 万相漫画 → 出刊`（小字）

**上屏文案**  

```
过载　　→ 先图后文，正文可折叠
术语拦路 → 当场说人话
启动难　→ 先站队，再补剧情
想带走　→ 竖屏分享图

一句话钩子 + 漫画，先入脑
（自动出刊，可规模化）
```

**口播**  

> 痛点怎么变成机制？过载就先图后文；术语就说人话；启动难就先站一队；想转发就生成竖屏分享图。供给侧用模型抓热点、改写成瓜、配漫画——可规模化，不是手工小报。一句话钩子加漫画，先入脑。

---



### P7 · 传播｜接头暗号 × 蒲公英（22s）★ 蒲公英主戏页

**画面（建议 Figma 结构）**  

1. 上半：接头暗号逻辑（短）
2. 下半或右侧：**一枚「种子卡」静帧**——蒲公英书签溢出卡片边界；底栏蒲公英图标 +「复制给同伙」
3. 可选极淡绒毛轨迹，面积要小
4. 不要满页黄底主题皮

**上屏文案**  

```
别当测试，当接头暗号
刷到自己的瞬间，他就想转

测完 → 开编辑部盲盒（认出自己）
吹一口 → 把种子交给风
落在谁身上，谁就是同伙
```

**种子卡上可印（短版，与产品一致）**  

```
编辑部盲盒已开
你是：〇〇（示例：通稿逃犯）

别收藏。吹给那个也读不完新闻的人——
种子落在谁身上，谁就是同伙。
```

**口播**  

> 传播上，我们不做专业测评。好不好玩，取决于你有多想对号入座。别当测试，当接头暗号——刷到自己，他就想转。认出自己之后，还有半程：像吹蒲公英一样发给同类。种子落在谁身上，谁就是同伙。现场你们会摸到「吹一口试试」。

**备注**：  

- 本页是全 PPT **唯一**蒲公英主视觉。  
- 不辩解「我们不是主题」。  
- 「吹一口」真机留给入口。

---



### P8 · 竞品｜为什么有空间（15s）

**画面**  

- 简洁对比表或四列：Axios / Newsletter / 大厂摘要 / 我们  
- 底一行机会句

**上屏文案**  

```
Axios　　　　精英简报，缩篇幅
Morning Brew　人格化语气，邮件关系
大厂 AI 摘要　压缩字数，通用能力
我们　　　　AI 风格迁移 + 结构化降维
　　　　　　降解码难度，并保留原文锚点

对标「严肃新闻 → 八卦体」的独立 Web，仍是蓝海
```

**口播**  

> 竞品要么缩篇幅，要么做人设邮件，要么做通用摘要。完全对标「用 AI 把严肃新闻变成八卦体」的独立 Web，仍是蓝海。我们做风格迁移加结构化降维——让人愿意读完，还愿意转给同伙。

---



### P9 · 后续｜真现场才有真需求（12s）

**画面**  

- 三个词大号：`订阅` `个性化` `真现场才有真需求`  
- 小字：进 1.2；MVP 先验证爽读与转发

**上屏文案**  

```
现场已听到：订阅 · 个性化
与脑暴一致，MVP 故意未塞满

先验证：能爽读 · 想转发
订阅与千人千面语气 → 1.2
```

**口播**  

> 现场已经听到订阅和个性化——和脑暴一致，只是 MVP 没塞满。先验证两件事：能不能爽读，会不会想转发。其余进 1.2。真现场，才有真需求。

---



### P10 · 证据｜正刊一眼（10s）

**画面**  

- 正刊首页或一条瓜大图：漫画 + 一句话吃瓜 + 来源示意  
- 可选角标「今日瓜王」若现场有

**上屏文案**  

```
正刊里，每条瓜都能这样吃
漫画 · 一句话钩子 · 可查来源
```

**口播**  

> 故事不是梗：正刊里每条瓜都是漫画、一句话钩子、可查来源。接下来，请大家跟编辑部对暗号——认出自己，再吹给同伙。

**衔接**：递麦给操作入口的伙伴。

若评委要求「团队页单独出现」，用 P2 缩略版再闪一次；否则 **删掉本页**，总页数变 11。

**画面**  

- 大字定位 + 体验指引  
- 二维码 / URL（正刊或入口）  
- **不要**用「就差你一个」（留给入口）

**上屏文案**  

```
AI 八卦特刊
利用好奇心，无痛阅读新闻

现场体验：编辑部入口 · 对暗号 · 吹一口
小工坊 · 小小痛点，好好安放
```

**口播**  

> AI 八卦特刊：把读不进去，做成读得爽、转得出的瓜。体验怎么上手，交给现场编辑部入口。

## 四、现场入口衔接（PPT 之后，约 90–120s）

沿用既有入口分镜，口播开头改为：

> 刚才是我们为什么做。接下来请你对暗号——然后吹一口，把种子交给风。


| 入口幕   | 要点                            | 蒲公英           |
| ----- | ----------------------------- | ------------- |
| s0–s2 | 溜走 / 卡点 / 盖章规矩                | 无             |
| s3–s4 | 对暗号 → 工牌揭晓                    | 无（查实章可仍用编辑部章） |
| 分享拍   | 按钮「吹一口试试」→ 满屏吹散 → 种子卡 → 复制给同伙 | **唯一主戏**      |
| s5    | 瓜田实习（说人话 / 站队 / 战书）           | 无             |
| s6    | 「今晚的瓜已经切好，就差你一个」→ 进正刊         | 无大图，至多角标      |

## 六、Figma 落地建议（教育版）

1. 建 Page：`Pitch · 黑客松`，Frame 尺寸 `1920×1080`（或 16:9）× 12。
2. 样式：纸色底 + 墨色字；避免全页鹅黄色。
3. 组件：种子卡做 Component（角色名作 Variant 文本）。
4. 导出：演示用 Figma Prototype 全屏，或导出 PDF 备用。
5. P7 蒲公英书签：PNG 可溢出 Frame 裁切，营造「飞出纸面」。

## 八、制作检查清单

- [ ] 无独立视频文件依赖；断网可投屏 PPT + 本机开入口  
- [ ] 全 PPT 蒲公英主视觉 ≤ 1 页（P7）  
- [ ] 未出现「我们不是做主题」类辩解句  
- [ ] 团队定义与三人分工已上 P2  
- [ ] 「就差你一个」未出现在 PPT  
- [ ] 类型名在 PPT、角色名在入口，不双线讲全  
- [ ] 彩排：PPT ≤ 3′ + 入口 ≤ 2′

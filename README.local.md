# AI 八卦特刊

> **Product One-Liner（30 字）**  
> 想跟上 AI 行业动态，正经新闻却总读不进去？八卦特刊，吃瓜读懂。

把严肃 AI 行业新闻改写成鲜活好读的八卦短刊：有漫画、有爆点、有来源，用好奇心降低阅读门槛，让局势丝滑入脑。

---

## 适合谁 / 不适合谁

### 核心需求

你想**跟上 AI 动态**，但一碰到严肃长文、通稿腔、术语堆就**读不进去**——AI 八卦特刊是为这个缺口设计的。

### 适合谁

| 类型 | 你可能的状态 | 特刊怎么帮你 |
|------|-------------|-------------|
| **过载型** | 高强度脑力劳动后，高密度文字耐受明显下降 | 短块 + 单爆点 + 漫画，降低单次阅读认知负荷 |
| **形式排斥型** | 对正经报道、通稿腔、无人物无冲突的结构天然没兴趣 | 把新闻写成有权谋、有得失、有戏剧性的行业瓜 |
| **学习厌恶型** | 不是不想知道，而是抗拒「我在上课 / 补课」的心理姿态 | 吃瓜式接收信息，保留事实与来源，但不给你上课感 |
| **执行型** | 启动难、易分心、读两行忘前两句（含 ADHD 倾向，无需诊断） | 首句交代主体、独立成篇、一句话吃瓜，方便碎片读与回忆 |

以上四类**可叠加**——很多人同时属于「形式排斥 + 执行型」，或「过载 + 学习厌恶」。

**尤其适合：**

- 不爱读板板正正新闻，但想跟上 AI 行业动态的人
- 偏好短、有画面、有钩子，而不是通稿和术语堆的人
- 愿意用「吃瓜」的方式接收信息，并偶尔点原文补细节的人

### 不适合谁

| 情况 | 为什么不适合 |
|------|-------------|
| **主题零兴趣** | 对 AI 本身完全不想知道——换什么形式都留不住 |
| **纯娱乐零信息** | 只想刷段子、完全不想带走任何事实或要点 |
| **深度建构需求** | 需要系统学原理、写研报、做技术决策——特刊是入门与跟动态，不是深度课 |
| **解码层困难** | 认字、断句本身就很痛苦——需要从阅读流畅度层面解决，而非换包装 |
| **纯被动且拒绝提取** | 连标题、一句话吃瓜都不想看——特刊仍假设你愿意接收压缩后的信息 |

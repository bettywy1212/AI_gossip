# AI 八卦特刊 (ai-gossip)

> 把严肃 AI 新闻改写成好读、好转发、带漫画配图的「行业瓜」——帮怕正经报道的人无痛跟上 AI 动态。

## 这是什么

**ai-gossip** 是一个 Cursor / Claude Agent Skill，专门把干巴巴的 AI 行业新闻，改写成鲜活、零门槛、适合社群传播的八卦特刊。

它不是假新闻，也不是标题党——而是用好奇心包装事实，把「谁在和谁较劲、谁的算盘响了、用户被怎样影响」写成短故事，让读者觉得「这瓜我得吃一口」。

每条产出 = **漫画配图 + 标题 + 八卦正文 + 一句话吃瓜 + 来源链接**。

## 适合谁

- 不爱读板板正正科技报道，但想跟上 AI 动态的人
- 需要在社群（微信群、小红书等）转发 AI 资讯的编辑/运营
- 女性社群是重要受众之一，但 skill 不依赖性别视角——默认走「行业瓜」轻八卦模式

## 能做什么

| 能力 | 说明 |
|------|------|
| 新闻改写 | 用户贴新闻直接改；没贴就联网搜当下最热 AI 资讯 |
| 轻八卦模式 | 默认。主体先出场，有趣来自权力/利益/时机/反差，不靠性别比喻 |
| 可选视角 | 实权模式 / 翻转模式（需显式指定） |
| 漫画配图 | 日常新闻→轻漫画；争议新闻→复古海报；格式按类型切换单/双/三格 |
| 自动叠字 | 纯画面生图 + 脚本自动叠加中文标题，无需二次确认 |
| 质量红线 | 禁止婚嫁隐喻、性别等级、性暗示；事实准确，保留来源 |

## 快速使用

在 Cursor 或 Claude 中调用 skill：

```
/ai-gossip
```

或指定模式：

```
/ai-gossip 轻八卦模式·独立成篇
/ai-gossip 实权模式·同一宇宙
```

## 项目结构

```
ai-gossip/
├── SKILL.md                      # Skill 主文件（Agent 读取）
├── references/
│   ├── writing-patterns.md       # 标题工艺、句式模板、正反示例
│   └── illustration-guide.md     # 配图类型判定、生图 brief、叠字规范
├── scripts/
│   └── overlay-text.ps1          # 中文叠字脚本
└── assets/
    ├── style-exploration/        # 配图风格探索样例
    └── issues/{日期}/            # 按日期归档的出刊成品
```

## 技术栈

- **Agent Skill**：Cursor / Claude Skills 格式（`SKILL.md`）
- **配图**：AI 生图（纯画面）+ PowerShell 自动叠字（`System.Drawing`）
- **联网**：需配合 web-access skill 或等效搜索能力获取热点新闻
